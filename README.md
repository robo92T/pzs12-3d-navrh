# PZS12 — 3D návrh webu

Statický web s interaktívnou CSS 3D kanceláriou a výrobou.

## Náhľad
Otvorte `index.html` v prehliadači. Na hostingu publikujte obsah koreňového priečinka; zostavenie nie je potrebné.

## Formulár
Formulár pripravuje e-mail cez `mailto:`. Nemá serverové odosielanie ani databázu.

## Obsah
Údaje poskytovateľa pochádzajú z https://www.pzs12.sk/. Právny prehľad odkazuje na zákon č. 355/2007 Z. z., overený k 22. 11. 2026. Pred verejným spustením treba dokončiť vizuálnu kontrolu a potvrdiť aktuálnosť údajov.
